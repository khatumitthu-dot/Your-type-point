YOUR TYPE DEMO / UPGRADED

Includes front shop + customer account + orders + tracking + per-size inventory + reviews + admin product/customer/order/review management + standalone information pages. Online payment is intentionally disabled; COD is used for demo orders.

Run locally: install Node.js 18+, then run `node server.js` from this folder. Open http://localhost:3000/
Admin: http://localhost:3000/admin.html
Set ADMIN_USER and ADMIN_PASS as environment variables before use. The bundled default is only for local demo and must be changed.

Before public launch: replace demo social links/contact/legal text, move from JSON storage to a managed database, enable HTTPS, configure backups, review authentication/security, and connect a payment gateway if desired.
